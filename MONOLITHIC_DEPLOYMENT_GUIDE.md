# 🏗️ Monolithic Repository Deployment Guide

## 📁 **Repository Structure**

```
lifepattern/
├── Dockerfile                    # Backend service (Go)
├── backend/                      # Backend source code
│   ├── cmd/
│   ├── internal/
│   ├── migrations/
│   └── ...
├── ai-service/                   # AI service (Python)
│   ├── Dockerfile               # AI service Dockerfile
│   ├── main.py
│   ├── models/
│   ├── utils/
│   └── ...
├── frontend/                     # Frontend (React Native)
├── render.yaml                   # Render configuration
└── ...
```

## 🚀 **Deployment Strategy**

### **Option 1: Using render.yaml (Recommended)**

The `render.yaml` file is configured to deploy both services automatically:

```yaml
services:
  # Backend Service (Go)
  - type: web
    name: lifepattern-backend
    dockerfilePath: ./Dockerfile          # Root Dockerfile
    dockerContext: .                      # Root context
    
  # AI Service (Python)
  - type: web
    name: lifepattern-ai-service
    dockerfilePath: ./ai-service/Dockerfile  # AI service Dockerfile
    dockerContext: .                         # Root context (monolithic)
```

### **Option 2: Manual Creation**

#### **Backend Service**
1. **Name**: `lifepattern-backend`
2. **Dockerfile Path**: `./Dockerfile`
3. **Docker Context**: `.` (root)
4. **Port**: `8080`

#### **AI Service**
1. **Name**: `lifepattern-ai-service`
2. **Dockerfile Path**: `./ai-service/Dockerfile`
3. **Docker Context**: `.` (root)
4. **Port**: `8000`

## 📋 **Deployment Steps**

### **Step 1: Create Services in Render**

#### **Using render.yaml (Auto-deploy)**
1. Go to [Render Dashboard](https://dashboard.render.com)
2. Click **"New +"** → **"Blueprint"**
3. Connect your GitHub repository
4. Render will automatically create both services from `render.yaml`

#### **Manual Creation**
1. **Create Backend Service**:
   - New Web Service
   - Name: `lifepattern-backend`
   - Dockerfile Path: `./Dockerfile`
   - Docker Context: `.`

2. **Create AI Service**:
   - New Web Service
   - Name: `lifepattern-ai-service`
   - Dockerfile Path: `./ai-service/Dockerfile`
   - Docker Context: `.`

### **Step 2: Environment Variables**

#### **Backend Environment Variables**
```
DATABASE_URL=postgresql://postgres:postgres@localhost:5432/lifepattern
JWT_SECRET=<auto-generated>
PORT=8080
ENVIRONMENT=production
CORS_ORIGIN=https://lifepattern-ai-dc5fe.web.app
AI_SERVICE_URL=https://lifepattern-ai-service.onrender.com
```

#### **AI Service Environment Variables**
```
PORT=8000
ENVIRONMENT=production
LOG_LEVEL=INFO
DRIFT_WINDOW_SIZE=30
DRIFT_THRESHOLD=0.05
```

### **Step 3: Verify Deployment**

```bash
# Check both services
./check_render_services.sh

# Test AI service specifically
./verify_ai_deployment.sh
```

## 🔍 **Troubleshooting**

### **Common Issues**

1. **Docker Build Fails**:
   - Verify Dockerfile paths are correct
   - Check that all required files exist
   - Ensure Docker context is set correctly

2. **Service Won't Start**:
   - Check service logs in Render dashboard
   - Verify environment variables
   - Check health check endpoints

3. **Import Errors**:
   - AI service: Drift detector imports are commented out
   - Backend: All Go dependencies are included

### **Service URLs**

After deployment:
- **Backend**: https://lifepattern-backend.onrender.com
- **AI Service**: https://lifepattern-ai-service.onrender.com
- **Backend Health**: https://lifepattern-backend.onrender.com/health
- **AI Health**: https://lifepattern-ai-service.onrender.com/health
